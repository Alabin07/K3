HTML

HTML är grundstrukturen för webbsidor. Det är ett märkspråk som används för att beskriva innehållet och strukturen på en webbsida.

Start på HTML är alltid:

            
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>

</body>
</html>

Vad är HTML?

HTML (HyperText Markup Language) är ett märkspråk som används för att skapa strukturen på webbsidor. Med HTML kan du definiera rubriker, textavsnitt, länkar, bilder, listor, tabeller, formulär och mycket mer.

Grundläggande HTML-element

Nedan följer några vanliga HTML-element:

  • <h1> till <h6>: Rubriker
  • <p>: Paragrafer
  • <a>: Länkar
  • <img>: Bilder
  • <ul>, <ol>, <li>: Listor
  • <table>, <tr>, <td>: Tabeller
  • <form>, <input>: Formulär

Rubriker och Paragrafer

Rubriker används för att skapa en hierarki i innehållet och paragrafer används för att strukturera text.

            
<h1>Detta är en rubrik</h1>
<p>Detta är en paragraf med lite text.</p>

Länkar

Skapa en länk med <a>-taggen:

            
<a href="https://www.example.com">Besök Example.com</a>

Bilder

Använd <img>-taggen för att visa bilder. Glöm inte att ange en alt-text för tillgänglighet:

            
<img src="bild.jpg" alt="Beskrivning av bilden">

Listor

Oordnade listor skapas med <ul> och ordnade listor med <ol>.

Exempel på oordnad lista:

            
<ul>
  <li>Första punkten</li>
  <li>Andra punkten</li>
  <li>Tredje punkten</li>
</ul>

Exempel på ordnad lista:

            
<ol>
  <li>Första punkten</li>
  <li>Andra punkten</li>
  <li>Tredje punkten</li>
</ol>

Tabeller

Tabeller används för att visa data i rader och kolumner.

            
<table border="1">
  <tr>
    <th>Rubrik 1</th>
    <th>Rubrik 2</th>
  </tr>
  <tr>
    <td>Data 1</td>
    <td>Data 2</td>
  </tr>
</table>

Formulär

Skapa formulär med <form>-taggen för att samla in användardata:

            
<form action="submit.html" method="post">
  <label for="name">Namn:</label>
  <input type="text" id="name" name="name">
  <input type="submit" value="Skicka">
</form>
