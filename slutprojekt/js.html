JavaScript

JavaScript är ett mångsidigt och kraftfullt programmeringsspråk som används för att skapa interaktivitet och dynamik på webbsidor. Tillsammans med HTML och CSS utgör det en av hörnstenarna i webbutveckling.

Variabler och Datatyper

I JavaScript används variabler för att lagra data. Du kan deklarera en variabel med var, let eller const. Vanliga datatyper inkluderar:

  • Number: Numeriska värden
  • String: Textsträngar
  • Boolean: true eller false
  • Object: Samlingar av nyckel-värde-par
  • Array: Listor av värden

Exempel på deklaration och tilldelning:

            
let tal = 5;
const namn = "Anna";
var ärAktiv = true;

Funktioner

Funktioner är block av kod som kan återanvändas. De definieras med function-nyckelordet:

            
function hälsa() {
    console.log("Hej världen!");
}

Du kan också skapa anonyma funktioner och peka dem till variabler:

            
const kvadrat = function(x) {
    return x * x;
};

Kontrollstrukturer

JavaScript stöder vanliga kontrollstrukturer som if-satser och loopar:

            
if (tal > 10) {
    console.log("Talet är större än 10");
} else {
    console.log("Talet är 10 eller mindre");
}

for (let i = 0; i < 5; i++) {
    console.log(i);
}

Händelsehantering

JavaScript används ofta för att hantera händelser på webbsidor, såsom klick eller tangenttryckningar:

            
document.getElementById("minKnapp").addEventListener("click", function() {
    alert("Knappen klickades!");
});

DOM-manipulation

Document Object Model (DOM) representerar strukturen av en webbsida. Med JavaScript kan du manipulera DOM för att ändra innehåll och struktur dynamiskt:

            
const rubrik = document.createElement("h1");
rubrik.textContent = "Dynamisk Rubrik";
document.body.appendChild(rubrik);
