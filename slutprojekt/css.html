CSS

CSS (Cascading Style Sheets) används för att styla och layouta HTML-innehåll. Med CSS kan du bestämma färger, typsnitt, marginaler, bakgrunder och mycket mer, vilket gör din webbsida visuellt attraktiv.

Grundläggande Syntax

En CSS-regel består av en selektor och ett deklarationsblock. Deklarationsblocket innehåller ett eller flera par med egenskaper och värden, avslutade med semikolon.

            
selector {
    egenskap: värde;
}

Exempel:

            
h1 {
    color: blue;
    font-size: 24px;
}

Olika sätt att lägga till CSS

Det finns tre huvudsakliga metoder för att använda CSS i en webbsida:

  • Extern CSS: Länka till en separat CSS-fil med <link>-taggen.
  • Intern CSS: Placera CSS-koden inuti ett <style>-element i <head>-sektionen.
  • Inline CSS: Använd style-attributet direkt på ett HTML-element.

Exempel på intern CSS:

            
<style>
  p {
      color: green;
  }
</style>

CSS Selektorer

Selektorer används för att välja de HTML-element du vill styla. Några vanliga selektorer är:

  • Elementselektor: Väljer alla element av en viss typ. Exempel: p
  • Klassselektor: Väljer element med en specifik klass. Exempel: .exempel
  • ID-selektor: Väljer element med ett specifikt ID. Exempel: #huvud

Exempel:

            
.important {
    font-weight: bold;
}
#header {
    background-color: lightgrey;
}

CSS Box Model

Boxmodellen beskriver hur element på en webbsida är uppbyggda. Den består av:

  • Content (innehåll)
  • Padding (utfyllnad)
  • Border (ram)
  • Margin (marginal)

Exempel:

            
div {
    margin: 20px;
    padding: 10px;
    border: 1px solid #000;
}

Kommentarer i CSS

Kommentarer kan användas för att förklara koden och ignoreras av webbläsaren.

            
/* Detta är en kommentar i CSS */
p {
    color: red;
}
